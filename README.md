# DATA550-FinalProj

## Description
The final report contains a brief description of the dataset used, a table of descriptive statistics, and a plot showing predicted lung cancer probability.

## How to generate
In a terminal, set the working directory to the project root directory, use the command `make Final_Proj2.html`.

## Code chunks
All the code is included the `Final_Proj2.rmd` file.
The part associated with table generating is an r-code chunk named `descriptive statistics`; the part associated with plot generating is an r-code chunk named `data analysis`.
